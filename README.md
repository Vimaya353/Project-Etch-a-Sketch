# Etch-a-Sketch

A browser-based Etch-a-Sketch project built using **HTML, CSS, and JavaScript**.

## Features

* 16 × 16 starting grid
* Grid squares created dynamically with JavaScript
* Flexbox-based grid layout
* Mouse hover drawing effect
* Custom grid sizes from 1 × 1 to 100 × 100
* Random RGB colors
* Progressive darkening effect

## Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Flexbox

## How to Run

1. Clone the repository.
2. Open `index.html` in a web browser.
3. Move the mouse over the grid to draw.
4. Click **New Grid** to create a different grid size.

## Project

This project was created as part of a JavaScript DOM manipulation exercise to practice creating and manipulating HTML elements dynamically.
